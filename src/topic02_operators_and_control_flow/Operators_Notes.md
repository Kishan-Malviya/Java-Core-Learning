# Operators
Operators in Java are special symbols or keywords which are used to perform operations on variables and values.
The data they operate on are called operands.
For example, in the expression int sum = a + b;, the symbol + is the operator and a and b are the operands.

Java categorizes operators based on their functionality and the number of operands they require.

### Arithmetic Operators
These are used to perform mathematical calculations.
1. (+ Addition / String Concatenation)
2. (- Subtraction)
3. (* Multiplication)
4. (/ Division - integer division discards decimals)
5. (% Modulus - returns the division remainder)

### Assignment Operators
These are used to assign values to variables & also performs mathematical operations before assigning.
1. = (Simply assign value to variable)
2. += (Perform addition then assign value)
3. -= (Perform substraction then assign value)
4. *= (Perform multiplication then assign value)
5. /= (Perform then assign value)

### Unary Operators
These are used to increment, decrement or invert the value.
1. ++ (Increment by 1)
2. -- (Decrement by 1)
3. ! (Inverts a boolean value)

### Relational (Comparison) Operators
These are used to compare two values.
1. == (Equals to)
2. != (Not Equals to)
3. < or > (Less than or Greater than)
4. <= or >= (Less than equals to or greater than equals to)

### Logical Operators
These are used to combine multiple boolean expressions.
1. && (Logical AND: returns true only if both conditions are true)
2. || (Logical OR: returns true if at least one condition is true)

### Ternary Operator
These are used as shorthand alternative to the if-else statement.

### Bitwise and Shift Operators
These are used to manipulate data at binary level.
1. & (Bitwise AND)
2. | (Bitwise OR)
3. ^ (Bitwise XOR)
4. ~ (Bitwise NOT)

### Type Checking Operator
1. instanceof - This is used to check if an object is an instance of a specific class or interface.
2. (type) - This is used to convert data from one data type to another data type.
